## Les six facettes

Dans le parcours complet (IPIP-NEO-120, Johnson, 2014), ce trait est mesuré par six facettes de
quatre questions chacune. Les libellés français sont des traductions du projet.

| Code | Facette (traduction du projet) | Nom original       |
| ---- | ------------------------------ | ------------------ |
| N1   | Anxiété                        | Anxiety            |
| N2   | Colère                         | Anger              |
| N3   | Humeur dépressive              | Depression         |
| N4   | Gêne sociale                   | Self-Consciousness |
| N5   | Impulsivité                    | Immoderation       |
| N6   | Vulnérabilité au stress        | Vulnerability      |

## Un trait qui peut évoluer

Une méta-analyse d'études longitudinales décrit des changements moyens des traits de personnalité au
cours de la vie (Roberts, Walton et Viechtbauer, 2006). Votre score décrit donc une tendance
actuelle, pas une identité figée.
